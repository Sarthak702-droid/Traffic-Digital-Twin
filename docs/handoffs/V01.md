# V01 recorded-clip processing handoff

- **Files:** `services/vision/recorded_clip.py` and `scripts/process-recorded-clip.py` add local clip registration, authorized-root/rights-reference checks, verified ITD checkpoint digest, configured geometry, full SHA-256 identity, atomic aggregate JSONL/manifest publication and exact cache validation. The ITD emitter uses causal half-open windows and provisional review labels. The concurrent/telemetry emitters no longer auto-label predictions as reviewed.
- **Interface:** invoke `scripts/process-recorded-clip.py` with camera, clip, authorized root, authorization reference and a verified model path. It outputs only aggregate-window metadata; source media and track IDs remain local. `NETWORK_CONFIG` selects the same network mapping used by Go/simulation/intelligence. Cache reuse preserves the processing source session and reports `cached_observations`.
- **Unit tests:** registration, changed clip/geometry/model, restart cache reuse, tamper rejection, missing/invalid windows, dependency failure, and a window-boundary crossing regression passed. The affected Python suite passed 86 tests in the Python 3.12 project `.venv` with real OpenCV, PyTorch and Ultralytics installed.
- **Real inference:** the original ITD v1.2 checkpoint was supplied and copied to ignored `.runtime/models/itd-v1.2/`; its SHA-256 matched the pinned digest `06006ecb5fe52a348ceed805bf0aa6b32af7e24e689d09a6582f6d53159d6b00`. CAM-01 clip SHA-256 `717af2bb3bc3f160dd41ccffebf73b2587dc8093f3f068df3929f7c862b60b8f` was processed on CPU with YOLO/ByteTrack. The full 58.6-source-second run emitted 12 contiguous finalized windows, including a final 3.6-second window, with five detected crossings. Fresh inference took 44.80 wall seconds and peaked at 1,760,416 KB RSS on this workstation; a subsequent cache run took 0.22 seconds and retained its source session. A corrupt MP4 produced a failed manifest and no JSONL. These local results are in ignored `.runtime/vision/processed/` and `.runtime/vision/corrupt-probe/`.
- **Limits:** detector output is provisional and has not been compared with independently reviewed reference labels. The clip authorization reference is operator-supplied; rights were not independently audited here. The old `run_camera_to_jsonl` entrypoint still emits legacy records without the new cache identity and must not be used as authoritative run input. V03/F01 and Q01 must connect and verify these observations through Go, simulation, intelligence and browser; this V01 result alone does not close full-stack or measurement-quality gates.
