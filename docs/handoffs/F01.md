# F01 — causal bound demand history

## Delivered

- Go passes the durable run input epoch and selected processed source identities to the private simulator on launch and recovery. C01's additive `RunCommand` contract extension (`f7a7333`) is the prerequisite.
- The simulator reads only the selected completed processed manifests, verifies their identity and observation checksum, and rejects missing, duplicate, reordered, degraded, or changed rows. A source bound to another network configuration fails reset before the active run changes.
- Video demand is released after each finalized source window; state carries at most 60 eligible bins per boundary, the bound input epoch, the latest finalized source window, and explicit missing, cached-valid, or stale quality. Simulation time is mapped one-to-one to source seconds for this recorded profile.
- The intelligence rollout and `Analyze` rebuild persistence or EWMA rates from the state snapshot's eligible history. Valid zero is preserved, and missing or stale history fails evaluation. Forecast state does not carry across runs or source sessions. Existing aggregate cell/backlog conservation remains intact.
