# Independent acceptance handoff

This handoff is prepared, not executed. No reviewer or operator action is implied. The developer has viewed and processed the existing clips; they are diagnostic inputs, not untouched recorded holdout. Physical control and production deployment remain deferred.

## Reference review owner

Obtain a new, authorized, previously unseen recorded clip with sufficient uninterrupted coverage. Keep media and model files in protected authorized roots outside git. Record authorization, immutable clip/config/geometry/model hashes, source session, source FPS/dimensions, requested coverage, actual decoded coverage and sampling metadata. Keep detector predictions separate from reference records.

Before processing or examining results, freeze the development/reserved chronological split, origins, metrics, count/queue thresholds, forecast horizons and resource budgets. Preserve all existing thresholds. Short recordings cannot establish 120/300-second recorded forecast accuracy; mark those horizons unavailable. Synthetic evaluation is model evidence, not physical corridor benefit.

Two distinct people independently label reserved window crossings by configured direction/class/lane, without treating detector output as ground truth. Reference queue labels require a declared visible queue region and supportable motion definition. Each reviewer records their own identity, actual UTC review timestamp, method and rights. Record disagreements and genuine adjudication, immutable source/config identity, source session, split and split protocol version. Do not prefill signatures, fabricate times, reuse one person under two identities, or run an emitter that asserts reviewed provenance.

Use the strict reference validator in `scripts/prototype_evaluation.py`. Rejected/missing provenance means no accuracy score. Store completed review records separately from predictions; export only aggregate evidence. Preserve every failed case and unavailable horizon.

Run the canonical bootstrap and non-mutating doctor in README. Provision their own protected server account; never commit credentials, media or tracking identities.

Confirm decoded coverage, finalized-window end, availability, source time, simulation time, forecast origin and quality appear distinctly. Valid zero counts remain valid.
