● CHAPTER 01 · THE CHALLENGE

Why a Digital Twin?

Urban traffic management today relies on reactive CCTV monitoring and manual signal timing.
Operators see what has already failed — never what is about to happen. Incident response is always too late.
We need a system that predicts, recommends, and proves impact before any action is taken.

● CHAPTER 05 · AI DECISION SUPPORT

Coordinated signal timing with strict safety envelopes

1

Multi-junction coordination

Instead of isolated timers, the system computes coordinated green splits across C1 and C3, clearing downstream before releasing upstream.

2

Safety-first validation

Every recommendation is bounded: 10s min green, 55s max green, 3–4s amber clearance, 2s all-red — violations are physically impossible.

3

Before-vs-After simulation

Operators run a virtual comparison in the digital twin. Same initial state, same seed — 4 objective metrics scored before any action is taken.

4

Transparent reasoning

Every recommendation explains what changed, why it helps, and which safety rules were validated. 100% traceable, zero hallucinated gains.

● CHAPTER 06 · INCIDENT RESPONSE

Proactive incident management

BOTTLENECK SCENARIO

C3 incident: 35% capacity retained

When a lane blockage reduces C3 capacity, the twin:
• Detects the bottleneck from queue growth patterns
• Meters inflow from C6 to prevent gridlock spillback
• Adjusts C1 cycle timing to clear the corridor
• Tracks recovery cycle-by-cycle — no false promises

EMERGENCY CORRIDOR

Ambulance priority: C6 → C3 → C1 → C2

Virtual green corridor for emergency vehicles:
• Cross-traffic safely halted via amber → all-red clearance
• 5-stage lifecycle: Scheduled → Clear → Priority → Recovery → Done
• Post-passage bounded recovery prevents lingering cross-traffic delays
• Manual safety locks override emergency commands with audit

💡 Key insight: Dynamic upstream metering during incidents protects the broader network from localized failures — preventing cascading gridlock.
